# Oasis Infobyte Data Science Internship Projects 🚀

This repository contains all four completed tasks for the **Oasis Infobyte Data Science Internship** program.

---

## 📌 Tasks Overview

### 🌸 Task 1: Iris Flower Classification
* **Objective:** Classify iris flowers into three distinct species (*setosa*, *versicolor*, *virginica*) using sepal and petal features.
* **Models Used:** K-Nearest Neighbors (KNN), Logistic Regression.
* **Visualizations:** Pairplots, Boxplots.

### 📉 Task 2: Unemployment Analysis with Python
* **Objective:** Analyze regional unemployment trends in India and measure the impact of the COVID-19 pandemic.
* **Techniques:** Data Cleaning, Aggregation, Heatmaps, Time-Series Plots, Pre- vs. Post-COVID Split Analysis.

### 🚗 Task 3: Car Price Prediction with Machine Learning
* **Objective:** Predict selling prices of used cars using features like mileage, age, fuel type, and transmission.
* **Models Used:** Linear Regression, Random Forest Regressor.
* **Evaluation:** MAE, RMSE, R² Score, Feature Importance Analysis.

### 📧 Task 4: Email Spam Detection with Machine Learning
* **Objective:** Classify emails as "Ham" (Legitimate) or "Spam".
* **Techniques:** TF-IDF Vectorization, Multinomial Naïve Bayes, Support Vector Machine (SVM).
* **Evaluation:** Confusion Matrix, Precision, Recall, F1-Score, Accuracy.
